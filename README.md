# Империя льда — сайт школы фигурного катания

Одностраничный сайт школы фигурного катания «Империя льда», Санкт-Петербург,
Красное Село, ул. Свободы 15, ледовая арена «Гололёд». Работает по адресу
[ice-imperia.ru](https://ice-imperia.ru).

Чистые HTML, CSS и JavaScript без сборщиков и фреймворков. Из сторонних
сервисов — только Google Apps Script как ретранслятор заявок в Telegram.
Требование к хостингу одно: **PHP 7 или выше**.

## Структура

```
index.php            главная страница
privacy.html         политика конфиденциальности
consent.html         согласие на обработку персональных данных
styles.css           стили
script.js            скрипты
send.php             приём заявок, отправка в Telegram и на почту
config.sample.php    образец настроек (рабочий config.php в репозиторий не входит)
gallery.php          автоматический список фотографий галереи
data/
  groups.json        группы, цены, расписание
  team.json          директор и тренеры
  render.php         сборка этих двух секций
  check.php          страница проверки файлов данных
cabinet/             личный кабинет: страницы
  login.html         вход, открывается по адресу /login
  index.html         кабинет, /cabinet/
api/                 личный кабинет: серверная часть
  index.php          единственный вход, разбор адреса
  core/              база, права, валидация, журнал, ошибки
  modules/           вход и дальше остальные разделы
db/                  личный кабинет: структура базы
  migrations/        нумерованные .sql
  migrate.php        применение миграций
  seed-admin.php     первый администратор, нужен один раз
tests/               проверка кода, на хостинг не нужна
assets/
  fonts/             шрифты Prata и Golos Text
  img/               фотографии
  img/gallery/       фотографии блока «Жизнь школы»
docs/                инструкции, скрипты обработки фото, код ретранслятора
```

## Что меняется без правки кода

| Что | Где |
|---|---|
| Группы, цены, расписание | `data/groups.json` |
| Директор и тренеры | `data/team.json` |
| Фотографии в галерее | положить файлы в `assets/img/gallery/` |
| Настройки формы заявок | `config.php` на хостинге |

После правки файлов данных откройте `/data/check.php` — страница проверит их
и покажет, что получилось. Подробные инструкции — в [docs/data-files.md](docs/data-files.md).

## Личный кабинет

В работе, ветка `feature/cabinet`. Четыре роли — администратор, тренер,
родитель, спортсмен — работают через один серверный API, к которому позже
подключатся мобильные приложения.

- [docs/cabinet/spec.md](docs/cabinet/spec.md) — роли, права, модель данных,
  правила абонементов, скидок и перерасчётов
- [docs/cabinet/api.md](docs/cabinet/api.md) — описание API
- `db/migrations/` — структура базы, применяется со страницы `/db/migrate.php`

Сделано: схема базы, ядро API, вход, страница входа **/login**
и кабинет **/cabinet/** — спортсмены, группы, расписание, отметки
посещаемости и журнал за месяц, тренеры, родители, тарифы, услуги,
настройки.
Ссылка на кабинет с публичного сайта не ведёт — адрес даётся тем, кому нужен.

Проверки: `php tests/run.php` — серверная часть, нужен только PHP;
`node tests/browser.js` и `node tests/browser-cabinet.js` — страницы
настоящим браузером, нужен Playwright. Подробности в [tests/README.md](tests/README.md).

Порядок развёртывания:

1. Создать базу в панели хостинга, вписать доступ и `migrate_key` в `config.php`
2. Открыть `/db/migrate.php?key=…` — создаст таблицы
3. Открыть `/db/seed-admin.php?key=…` — заведёт первого администратора
4. Проверить `/api/v1/ping` — должен ответить `{"ok":true}`
5. Открыть `/login` и войти учётной записью администратора

## Публикация

Содержимое репозитория кладётся в корень сайта (`public_html`), кроме папки
`docs/` — она нужна только для работы с проектом. Отдельно, один раз,
на хостинг загружается `config.php`: скопируйте `config.sample.php`,
заполните и положите рядом с `send.php`. Без него форма заявок не работает.

Полная инструкция по загрузке и проверке — [docs/README.md](docs/README.md).
