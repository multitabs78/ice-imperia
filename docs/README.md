# Империя льда — сайт школы фигурного катания

Статический сайт на чистом HTML, CSS и JavaScript. Из сторонних сервисов —
только Google Fonts. Единственное требование к хостингу: поддержка **PHP 7 и выше**
(нужна для отправки заявок в Telegram).

---

## 1. Что загружать

Загрузите на хостинг всё содержимое этой папки в корень сайта
(обычно это `public_html`, `www` или `httpdocs`), сохранив структуру:

```
index.php           главная страница
privacy.html        политика конфиденциальности
consent.html        согласие на обработку персональных данных
styles.css          стили
script.js           скрипты
send.php            приём заявок и отправка в Telegram
config.php          настройки формы — заполняется один раз, см. раздел 2
config.sample.php   образец настроек
gallery.php         автоматический список фотографий галереи
data/
  groups.json       группы, цены, расписание  ← правится вручную
  team.json         директор и тренеры        ← правится вручную
  render.php        сборка этих двух секций
  check.php         страница проверки файлов данных
  cache/            исправные копии, страховка от опечаток
robots.txt          для поисковых систем
sitemap.xml         карта сайта
.htaccess           сжатие, кеширование и выбор главной страницы (Apache)
assets/
  fonts/            шрифты
  img/              фотографии
  img/gallery/      фотографии для блока «Жизнь школы»
```

Файлы из папки `docs/` (`README.md`, `data-files.md`, `fonts.md`,
`telegram-relay.*`, `optimize-gallery.*`) на хостинг загружать не нужно.

**Если на сайте уже лежит `index.html`** — удалите его после загрузки
`index.php`, иначе на части хостингов продолжит открываться старая версия.
Ссылка `/index.html` перенаправляется на главную.

## 2. Обязательно заполнить перед публикацией

### Настройки формы — файл config.php

Все настройки отправки заявок лежат в отдельном файле `config.php` в корне
сайта. В репозиторий он не входит: в нём ключи и адреса. Чтобы его получить,
скопируйте `config.sample.php` под именем `config.php` и заполните.

```php
'chat_id'   => '-1001234567890',   // чат, куда приходят заявки
'relay_url' => 'https://script.google.com/macros/s/.../exec',
'relay_key' => 'тот же пароль, что в RELAY_KEY скрипта Apps Script',
'email_to'  => 'почта@школы.ru',   // запасной канал
```

Токен бота в `config.php` **не нужен**: на этом хостинге заявки идут через
ретранслятор, и токен хранится в свойствах скрипта Google Apps Script.

Как узнать `chat_id`: добавьте бота в нужный чат, напишите там любое сообщение
и откройте в браузере `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` —
в ответе будет поле `chat.id`.

Если бот пишет в группу, дайте ему права администратора или отключите режим
приватности в @BotFather — иначе он не увидит чат.

Без `config.php` форма отвечает «Форма не настроена», а в лог ошибок PHP
попадает строка с объяснением. Проверить, видит ли сайт файл, можно
на `send.php?selftest=1` — первая строка ответа так и называется, `config.php`.

**Проверка связи.** `https://ваш-сайт/send.php?selftest=1` показывает, доступны ли
Telegram напрямую и ретранслятор. `https://ваш-сайт/send.php?selftest=send`
дополнительно отправляет настоящее тестовое сообщение в чат и письмо на почту —
по нему видно, доходит ли заявка до конца.

**Если хостинг не пускает к Telegram.** В ответе `selftest=1` будет Если там `Connection timed out` —
исходящие соединения к `api.telegram.org` закрыты. Что делать:

1. Написать в поддержку хостинга с просьбой открыть исходящие соединения
   к `api.telegram.org` по порту 443.
2. Заполнить в `config.php` поля `email_to` и `email_from` — заявки
   будут приходить письмом, пока вопрос решается. Это резервный канал:
   он включается автоматически, только если Telegram не ответил.
3. Развернуть ретранслятор и указать его адрес в `relay_url`, а пароль —
   в `relay_key`. Тогда заявки пойдут в Telegram в обход блокировки:
   хостингу нужно достучаться только до ретранслятора.

   Есть два готовых варианта, оба бесплатные, инструкции внутри файлов:

   - `telegram-relay.gs` — Google Apps Script. Проще: нужен только
     аккаунт Google, разворачивается через браузер за десять минут.
     Умеет дополнительно вести журнал заявок в Google Таблице.
   - `telegram-relay.js` — Cloudflare Worker. Быстрее работает,
     но требует регистрации в Cloudflare.

### Адрес сайта

Адрес `https://ice-imperia.ru` прописан в `index.php` (`canonical`, `og:url`,
`og:image`) и в `robots.txt` (`Sitemap`). Если домен сменится, поправьте
эти четыре места — они отвечают за то, как выглядит ссылка в мессенджерах.

## 3. Что ещё стоит дополнить

Все места помечены в коде комментариями вида `<!-- добавить ... -->`.
Найти их можно поиском по слову «добавить».

- **Тренеры** (`index.html`, секция «Команда») — четыре карточки-заглушки.
  Нужны фотографии, имена, должности и по одной-две строки описания.
  Фотографии положите в `assets/img/` как `coach-1.jpg`, `coach-2.jpg` и так далее
  и раскомментируйте строку с `<img>` внутри карточки.
- **Акции** — сейчас нейтральный текст «Узнайте, какие предложения действуют сейчас».
- **Вопросы и ответы** — два ответа оставлены заглушками: что взять на первое
  занятие и можно ли родителю присутствовать на арене.
- **Карта** в футере — при желании вставьте `iframe` Яндекс.Карт,
  место отмечено комментарием.

## 4. Как редактировать содержимое

- **Группы, цены и расписание** — файл `data/groups.json`.
- **Директор и тренеры** — файл `data/team.json`.
- **Фотографии галереи** — просто положить файлы в `assets/img/gallery/`
  (раздел 6 ниже).

Эти три вещи меняются без правки разметки. Подробные инструкции с примерами —
в отдельном файле **`docs/data-files.md`**. После каждой правки открывайте
`https://ice-imperia.ru/data/check.php` — страница проверит файлы и покажет,
что получилось.

Остальные тексты лежат в `index.php` между тегами, править их безопасно.

- **Подпись кнопки** формы можно менять прямо в разметке — скрипт её подхватит.
- **Телефон** встречается в нескольких местах. Меняя его, не забудьте про
  атрибуты `href="tel:+79992154556"` — там номер пишется без пробелов и скобок.

## 5. Проверка после загрузки

1. Откройте сайт и отправьте тестовую заявку — сообщение должно прийти в Telegram.
2. Проверьте вторую форму: карточка группы → «Расписание и подробнее» →
   «Записаться в группу». В сообщении должна быть строка «Группа».
3. Откройте `/data/check.php` — оба файла данных должны быть отмечены зелёным,
   а страховка от опечаток — работать.
4. Убедитесь, что секции «Команда» и «Группы и абонементы» на месте:
   четыре человека в команде и семь групп.
5. Посмотрите сайт с телефона: меню-бургер, карточки групп, мозаика фотографий.
6. Убедитесь, что ссылки «Политика конфиденциальности» и «Согласие на обработку
   персональных данных» в футере открываются.

Если заявка не отправляется, форма покажет сообщение с телефоном, а причина
запишется в лог ошибок PHP на хостинге — там будет ответ Telegram.

**Важно:** `index.php` нельзя открыть двойным щелчком с диска — ему нужен
хостинг с PHP. Смотреть результат правок можно только на сайте.

## 6. Как добавить фотографию в галерею

В папке `docs/` лежат скрипты обработки на ImageMagick:
`optimize-gallery.sh` (macOS, Linux) и `optimize-gallery.ps1` (Windows).

Они уменьшают снимок до 1600 px по длинной стороне, выпрямляют его по
данным съёмки, приводят к sRGB, **удаляют EXIF вместе с геометкой**,
слегка подшарпливают после уменьшения и сохраняют прогрессивный JPEG.
Исходники не изменяются, результат складывается в отдельную папку.

```
sh optimize-gallery.sh ~/Снимки/новые ~/Готовые          # macOS, Linux
.\optimize-gallery.ps1 -Src C:\Снимки -Dst C:\Готовые    # Windows
```

Снимок из камеры весом около мегабайта после обработки занимает
100–150 КБ без заметной потери качества.

Дальше:

1. Положите готовые файлы в `assets/img/gallery/`.
2. В `index.html` найдите список `data-photos` в секции «Жизнь школы»
   и добавьте строку:

```json
{"src":"assets/img/gallery/имя-файла.jpg","alt":"Короткое описание кадра"}
```

3. Поменяйте версию в двух строках `index.html` — `styles.css?v=…`
   и `script.js?v=…`, иначе у посетителей останется старая версия из кеша.

Файл `optimize-gallery.ps1` сохранён в кодировке UTF-8 с BOM — иначе
Windows PowerShell читает русский текст как набор символов и отказывается
запускать скрипт. Если будете его править, сохраняйте в той же кодировке.

Имена файлов только латиницей, строчными буквами, через дефис:
хостинг на Linux различает регистр, а кириллица в путях создаёт проблемы.
Скрипты переименовывают такие файлы автоматически.

## 7. Шрифты

Сайт не обращается к Google Fonts: внешних запросов при загрузке нет.
Как подключить свои шрифты и что важно знать про кириллицу — в файле
`docs/fonts.md`.
