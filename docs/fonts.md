# Шрифты сайта

Сайт не обращается к Google Fonts: файлы лежат в `assets/fonts/`,
внешних запросов при загрузке нет.

| Где | Гарнитура | Файл |
|---|---|---|
| Заголовки | **Prata** | `prata-400.woff2` |
| Основной текст | **Golos Text** | `golos-text-400.woff2` |
| Телефон, ссылки | Golos Text 500 | `golos-text-500.woff2` |
| Подписи, кнопки, метки | Golos Text 600 | `golos-text-600.woff2` |

Обе гарнитуры содержат кириллицу, поэтому русский текст набирается
именно ими. Курсив и остальные насыщенности на сайте не встречаются —
их качать не нужно.

Шрифты заданы двумя переменными в начале `styles.css`:

```css
--font-display:"Prata",Georgia,"Times New Roman",serif;
--font-text:"Golos Text",-apple-system,BlinkMacSystemFont,"Segoe UI",Roboto,"Helvetica Neue",Arial,sans-serif;
```

Дальше в списке — системные запасные варианты: если файл не загрузится,
текст всё равно будет читаться.

---

## Как сменить гарнитуру

1. Скачайте шрифт в формате **woff2** — он самый лёгкий и понятен
   всем современным браузерам.
2. Положите файлы в `assets/fonts/`.
3. В `styles.css` поправьте имена в блоке `@font-face` (их четыре),
   пути к файлам и две переменные выше.
4. Поменяйте версию в ссылках `styles.css?v=…` и `script.js?v=…`
   в `index.html`, `privacy.html` и `consent.html`, иначе у посетителей
   останется старая версия стилей из кеша.

Гарнитура обязательно должна содержать кириллицу, иначе русский текст
будет выводиться системным шрифтом, а файл — грузиться впустую.

---

## Что можно ещё ужать

Если при скачивании были выбраны все наборы символов, в файлах лежат
латиница, латиница расширенная, кириллица, кириллица расширенная,
иногда греческий и вьетнамский. Сайту нужны только кириллица
и базовая латиница.

На сервисе google-webfonts-helper наборы выбираются галочками перед
скачиванием. Для Prata это обычно даёт около трети веса, для
Golos Text — меньше, но тоже заметно. Сейчас четыре файла весят 112 КБ.

## Что уже сделано для скорости

- `font-display: swap`: текст виден сразу, шрифт применяется по мере
  загрузки, страница не остаётся пустой.
- Подключены только четыре начертания вместо всего семейства.
- Шрифты объявлены через переменные: чтобы сменить гарнитуру на всём
  сайте, достаточно поправить две строки.
