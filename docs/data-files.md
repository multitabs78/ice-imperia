# Расписание и тренеры: где это менять

Группы, цены, расписание и тренеры больше не зашиты в разметку. Они лежат
в двух текстовых файлах, а страница собирается из них сама:

```
data/groups.json    группы, стоимость, расписание
data/team.json      директор и тренеры
data/render.php     сборка разметки — трогать не нужно
data/check.php      страница проверки файлов
data/cache/         исправные копии, страховка от опечаток
```

Порядок работы всегда один и тот же:

1. Скачать нужный файл с хостинга (`data/groups.json` или `data/team.json`).
2. Открыть в текстовом редакторе — **Notepad++**, **VS Code** или «Блокнот».
   Сохранять строго в кодировке **UTF-8**.
3. Залить обратно в папку `data/`.
4. Открыть `https://ice-imperia.ru/data/check.php` — страница скажет,
   всё ли в порядке, и покажет, что получилось.
5. Обновить сайт (Ctrl+F5) и посмотреть результат.

Правила записи простые: текст всегда в двойных кавычках, между элементами
списка — запятая, после последнего элемента запятой нет.

## Расписание и цены — `data/groups.json`

Файл состоит из трёх частей: заголовок секции (`head`), блоки групп (`sets`)
и призыв в конце (`cta`).

### Поменять цену или расписание

Найдите нужную группу по названию и исправьте значение:

```json
{
  "age": "3–6 лет",
  "name": "СОГ-1",
  "full": "Спортивно-оздоровительная группа",
  "price": "14 400 ₽",
  "per": "в месяц",
  "facts": [
    "8 занятий в месяц",
    "1-й год обучения",
    "Лёд, ОФП/СФП и хореография"
  ],
  "desc": "Первые шаги на льду, базовые навыки и знакомство с фигурным катанием.",
  "schedule": {
    "ВТ": ["16:30 лёд", "17:45 зал"],
    "ВС": ["17:45 хореография", "19:00 лёд"]
  }
}
```

В расписании первое слово — время, остальное — пояснение. То есть
`"16:30 лёд"` превращается на сайте в **16:30** лёд. Дни идут в том порядке,
в каком записаны в файле.

### Что означает каждое поле

| Поле | Что это | Обязательное |
|---|---|---|
| `name` | Название группы. Оно же уходит в заявку вместе с заявкой родителя | да |
| `age` | Возраст, строкой: `"3–6 лет"` | нет |
| `full` | Расшифровка названия под заголовком | нет |
| `price` | Стоимость со знаком рубля: `"14 400 ₽"`, `"от 29 500 ₽"` | нет |
| `per` | Приписка под ценой: `"в месяц"` | нет |
| `facts` | Короткие строки списком | нет |
| `desc` | Одно-два предложения под списком | нет |
| `schedule` | Дни и время | нет |
| `mark` | Плашка вроде `"Для первого знакомства"` | нет |
| `accent` | `true` — карточка выделяется цветом | нет |
| `hide` | `true` — группа временно не показывается | нет |

Пустое поле можно оставить пустой строкой (`"desc": ""`) или удалить
вместе со строкой — результат одинаковый.

### Добавить группу

Скопируйте любую карточку целиком — от `{` до `}` — вставьте рядом,
не забыв запятую между карточками, и поменяйте содержимое. Больше ничего
делать не нужно: номера панелей, кнопка «Расписание и подробнее» и передача
названия в заявку настраиваются сами.

Карточки в блоке выстраиваются по три в ряд, если их число делится на три,
иначе по две. На телефоне всегда одна в ряд.

### Убрать группу на время

Добавьте в карточку строку `"hide": true,` — группа исчезнет с сайта,
но данные сохранятся. Уберёте строку — вернётся.

### Добавить блок групп

Блок — это заголовок с пояснением и карточки под ним («Начало пути»,
«Спортивное развитие», «Для себя»). Скопируйте блок целиком и поменяйте
`title`, `note` и карточки.

### Варианты абонемента

Если у группы есть дополнительные варианты оплаты, добавьте в карточку:

```json
"extra": {
  "title": "Варианты абонемента",
  "rows": ["16 занятий — 26 000 ₽", "24 занятия — 34 000 ₽"]
}
```

## Тренеры — `data/team.json`

Директор описан отдельно (`lead_card`) — у него широкая карточка сверху.
Остальные идут списком в `coaches` в том порядке, в каком записаны.

```json
{
  "name": "Иевлев Роман Юрьевич",
  "role": "Тренер по фигурному катанию",
  "rank": "КМС",
  "discipline": "Одиночное катание",
  "photo": "coach-ievlev",
  "facts": [
    "Победитель и призёр юниорских соревнований",
    "Участник международных ледовых шоу"
  ]
}
```

| Поле | Что это |
|---|---|
| `name` | Фамилия, имя и отчество |
| `role` | Должность |
| `rank` | Звание крупными буквами: `"КМС"`, `"МС"` |
| `discipline` | Направление рядом со званием |
| `photo` | Имя файла фотографии **без расширения** |
| `facts` | Достижения и образование списком |
| `alt` | Подпись для поисковиков. Если не указать — составится из имени и должности |
| `hide` | `true` — тренер временно не показывается |

### Добавить тренера

1. Обработайте фотографию тем же скриптом, что и фото для галереи
   (вертикальный кадр, 900×1125). Назовите по образцу: `coach-familiya.jpg`.
2. Положите её в `assets/img/`. Если рядом будет лежать `coach-familiya.webp`,
   сайт подключит облегчённую версию сам — специально ничего прописывать не надо.
3. Скопируйте карточку любого тренера в `data/team.json`, поменяйте поля,
   в `photo` напишите `"coach-familiya"` — без `.jpg`.
4. Проверьте на `/data/check.php`: страница скажет, нашлись ли файлы фотографии.

Размеры фотографии подставляются автоматически из самого файла, поэтому
кадр другой пропорции не поедет.

### Тренер есть, фотографии ещё нет

Оставьте `"photo": ""` — карточка останется в файле, но посетителям
показываться не будет. Так сейчас записан хореограф: данные ждут своей
фотографии. Как только в `photo` появится имя файла, карточка возникнет
на сайте сама.

Поле `"hide": true` нужно для другого случая — когда и фотография, и данные
на месте, но человека временно не надо показывать.

## Если что-то сломалось

Пропущенная запятая или незакрытая кавычка делают файл нечитаемым. На этот
случай есть страховка: при каждой удачной загрузке исправная копия файла
сохраняется в `data/cache/`. Если в файле появится опечатка, сайт покажет
последнюю рабочую версию секции — посетители ничего не заметят.

Чтобы найти опечатку, откройте `/data/check.php`: страница назовёт файл,
номер строки и покажет саму строку.

Страховка работает, только если папка `data/cache/` существует и доступна
для записи (права 755). Это тоже проверяется на `/data/check.php`.

## Что ещё редактируется без кода

- **Фотографии в галерее** — просто положить файлы в `assets/img/gallery/`,
  подписи при желании добавить в `assets/img/gallery/alt.json`.
  Подробнее — в README, раздел «Как добавить фотографию в галерею».
- **Всё остальное** (тексты блоков «О школе», «Первое занятие», акции,
  вопросы и ответы, футер) пока лежит в `index.php` — это обычный текст
  между тегами, править его безопасно.
